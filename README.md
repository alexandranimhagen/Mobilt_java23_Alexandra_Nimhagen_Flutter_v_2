Mobile Flutter App – Java YH Course (Flutter v2)

A mobile app built using **Flutter** and **Dart** as part of a Java YH-course. Demonstrates UI development, navigation, state management, and simple API integration.

Features

- Cross-platform mobile UI with Flutter widgets  
- Navigation between multiple screens  
- State management (StatefulWidgets or Provider)  
- Fetching and displaying data from a REST API  
- User interactions via buttons, forms, or lists

Technologies Used

- Flutter & Dart  
- HTTP package for API calls  
- State management (setState / Provider / Bloc)  
- JSON parsing
- Android & iOS compatibility

How to Run

   ```bash
   git clone https://github.com/alexandranimhagen/Mobilt_java23_Alexandra_Nimhagen_Flutter_v_2.git
